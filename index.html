🖨 はじめて印刷するとき（Bambu Studio の手順）
  1. 「STLを保存」を押すと、パソコンの「ダウンロード」フォルダにファイルが入ります。
  2. Bambu Studio を開き、プリンタが Bambu Lab A1 mini（0.4mmノズル） になっているか確かめます。
  3. 保存したSTLを画面の中にドラッグ＆ドロップ（または「ファイル」→「インポート」）。
  4. フィラメントは PLA、設定は 0.20mm Standard のままでOK。サポートはオフ（このツールのグッズはサポートなしで刷れる形にしてあります）。
  5. 右上の「プレートをスライス」→ 時間と材料を確かめて「印刷」。
👩‍🏫 研修で使うときの進め方（例：60分）
時間内容
0〜10分実物を回して触ってもらう（事前に刷った評価スタンプ・分数円・ソーマキューブ・点字プレートなど）
10〜25分各自がこのページで1つ選び、自分の教室・子ども・教材に合わせて寸法を決める（定規・ノギスで実測）
25〜35分STLを保存 → Bambu Studio でスライス → 時間と材料を読む
35〜60分代表の1点を実際に印刷（時間は事前に確認）。待ち時間に「自分の授業ならどう使う？」「どこを測って決めた？」を出し合う
  • 研修中に完成まで見せるのは、事前に Bambu Studio でスライスして時間を確かめた1点だけにすると安心です（小さいもの：鉛筆グリップ・カードスタンド・点字プレートなど）。プリンタが1台なら、全員のゴール＝寸法を決めてSTLを保存し、Bambu Studio でスライスするまで、代表の1点だけを実際に印刷して見せます。
  • フィジェット（なでなで石・触感タイル・迷路）としくみフィジェット（遊星ギヤ・歯車の列・名前いもむし・らせんくぐり・びよーんスパイラル・パチパチスイッチ）は、「授業中に一人で使う」「活動として使う」「休み時間に使う」を分けて考えます。使う場面・置き場所・回収のしかたを決め、学習のじゃまになるなら見直す。待ち時間の5分で話し合うのもおすすめです。
  • 子どもに「これ、先生が寸法を決めて作ったんだよ」と言えるのがねらいです。人気作をそのまま落とすのではなく、自分の教室に合わせて数値を決めるところに価値があります。
  • ネームマグネットの名簿は、この画面の中だけで処理されます（サーバーに送られません）。URLコピーにも名簿は入りません。
📏 うまくいかない時は
  • きつくて入らない／ゆるい：プリンタごとに 0.1〜0.3mm ずれます。寸法を少し変えて作り直すのが一番の近道です。
  • 角がベッドからはがれる：ベッドを中性洗剤で洗って油分を落とす。Bambu Studio で「ブリム」をオンにする。
  • 糸を引く：フィラメントが湿気を吸っているかも。乾燥させるか、新しいものに。
