# 先生の便利グッズ工房
職員室の便利グッズ・授業の教材教具・UD/特別支援の道具・フィジェット・しくみフィジェットの40種を、寸法を合わせて A1 mini 用 STL にする単一HTML（先生向け研修用）。

## 使い方
`index.html` をブラウザで開く（形の計算に manifold-3d を CDN から読むので、ネット接続が必要）。
上の「はじめての方は」の入口か、左の一覧（分類タブ・検索でしぼれる）からグッズを選ぶ → 右のつまみ（数値入力も可）で寸法 → 「STLを保存」→ Bambu Studio にドラッグ。もっと自由に設計したい人向けに、右上から ガジェットCAD（monozukuri-koubou/gadget-cad.html）へリンク。

## 収録グッズ（40種）
- **職員室・教室の便利グッズ（14）**：番号札（1〜40などを一括・穴／磁石／板だけ）／パイプクリップ（机のパイプにはめるフック、よこ用・たて用、試験片あり）／ホワイトボードマーカー立て／スマホ・タブレットスタンド／黒板用ネームマグネット（名簿から一括）／机上ネームプレート・席札（文字板＋台の2部品）／名前キーホルダー／袋クリップ／SD・USBメモリ立て／電池ケース／付箋ホルダー／カード・席札スタンド／評価スタンプ（自作はんこ）／チョークホルダー
- **授業で使う教材・教具（10）**：原子モデルマグネット（元素記号を並べて入力）／大きなノギス模型（あり形の本尺＋副尺1/10のスライダー）／立方体の切断模型（正三角形・長方形・ひし形・正六角形、サポート不要の向きに自動で置く）／タングラム（ケースつき）／音符マグネット（全・2分・4分・8分、たまの高さ＝五線の間隔）／体積くらべ（柱と錐の容器）／分数円／時計の学習模型／試験管立て／ソーマキューブ
- **だれでも使いやすく（UD・特別支援）（6）**：トークンボード（くぼみの板＋星・ハート・二重丸のコマ）／触って読める定規（1cm・5mmの山、5cmごとに点）／点字ネームプレート（かな→点字変換）／鉛筆グリップ／ペットボトルオープナー／リーディングガイド
- **さわって使う・遊ぶ（フィジェット）（3）**：なでなで石（ワーリーストーン）／さわって探そう 触感タイル／ビー玉迷路（番号から毎回ちがう迷路）
- **回る・のびる・しなる（しくみフィジェット）（7）**：リンク機構（4節リンクの組立式。グラスホフの判定・てこのゆれ角・当たりの有無を画面に表示）／パチパチスイッチ（双安定・角度3種の比べるセット）／遊星ギヤ・スピナー（ヘリンボーン、一体印刷）／まわしてギヤ（つづみ形の軸の歯車列、一体印刷、速度伝達比）／名前いもむし（フレキシ、1文字1コマ）／らせんくぐり（対数らせんの円すいが同じ形の穴を回って通る）／びよーんスパイラル

各グッズに「人気の理由（出典リンク）」「先生が測るところ」「授業・学級で使うなら」「印刷のしかた」「使い方」を表示。はめあいが大事なもの（チョーク・時計・鉛筆グリップ・袋クリップ・オープナー）には「まず試験片を作る」がある。形状はすべてオリジナル。ガジェット工房（monozukuri-koubou）とは品目が重ならない。

## 作り方（開発）
- `_work/geom.js`（形状）・`_work/catalog.js`（一覧・つまみ・説明文）・`_work/shell.html`（画面）を編集 → `node _work/build.js` で `index.html` を生成。
- グッズ単位の差し替え：`_work/parts/<id>.js` を書いて `python _work/swap_builder.py <id>`。
- 検証: `node _work/test.js [id] [ランダム回数]`（水密・1部品・接地・プレート内）、`node _work/shot.js 1400`（Edge ヘッドレスでスクショ）、`node _work/dl.js <フォルダ>`（実際に保存されるSTLを全プレート分）、`python _work/montage.py`（レビュー用一覧画像）、`node _work/kin.js [id]`（しくみフィジェットを回して干渉・らせんくぐりの通りぬけ）、`python _work/oh.py <フォルダ>`（STLの水密・張り出し）。
- node_modules は `01_アプリ/monozukuri-koubou/_work/node_modules` を借りている。
- Codex レビュー：`_work/review1.md`〜`review8.md`（20種で77→88→93→96点、フィジェット追加後 93→96点、しくみフィジェット5種＋一覧UI後 92→96点）。
- Codex 呼び出しの注意：`-i`（画像添付）を付けると依頼文が届かないことがあった。画像は依頼文に絶対パスで書いて開いてもらう。
